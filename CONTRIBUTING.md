# 贡献指南 / Contributing Guide

> 感谢您对"玄学是科学吗？"项目的关注！我们欢迎各种形式的贡献。
> Thank you for your interest in the "Is Fortune-Telling Science?" project! We welcome contributions of all kinds.

## 🤝 如何贡献 / How to Contribute

### 1. 报告问题 / Report Issues
如果您发现了问题或有改进建议，请：/ If you find issues or have improvement suggestions, please:
- 使用 [Issues](https://github.com/xianyu564/divination-vs-science/issues) 页面 / Use the [Issues](https://github.com/xianyu564/divination-vs-science/issues) page
- 选择适当的标签（bug、enhancement、documentation等）/ Select appropriate labels (bug, enhancement, documentation, etc.)
- 提供详细的问题描述和复现步骤 / Provide detailed problem description and reproduction steps

### 2. 提交内容 / Submit Content
如果您想贡献代码或内容：/ If you want to contribute code or content:

#### 内容贡献 / Content Contributions
- **讲座材料改进 / Lecture Material Improvements**: 优化现有讲座的设计、内容或结构 / Optimize design, content, or structure of existing lectures
- **讲者笔记 / Speaker Notes**: 补充或改进讲者笔记 / Supplement or improve speaker notes
- **学术资源 / Academic Resources**: 添加新的学术资料或研究材料 / Add new academic materials or research materials
- **FAQ内容 / FAQ Content**: 补充常见问题和答案 / Supplement common questions and answers
- **翻译 / Translation**: 将内容翻译成其他语言 / Translate content into other languages

#### 代码贡献 / Code Contributions
- **工具开发 / Tool Development**: 开发相关的工具或脚本 / Develop related tools or scripts
- **模板改进 / Template Improvements**: 优化现有模板 / Optimize existing templates
- **自动化 / Automation**: 改进工作流程或自动化脚本 / Improve workflows or automation scripts

### 3. 文档改进 / Documentation Improvements
- 改进README文件 / Improve README files
- 添加使用说明 / Add usage instructions
- 完善注释和文档 / Improve comments and documentation

## 📋 贡献流程 / Contribution Process

### 第一步：Fork 项目 / Step 1: Fork the Project
1. 点击项目页面的 "Fork" 按钮 / Click the "Fork" button on the project page
2. 克隆您的fork到本地：/ Clone your fork to local:
   ```bash
   git clone https://github.com/YOUR_USERNAME/divination-vs-science.git
   cd divination-vs-science
   ```

### 第二步：创建分支 / Step 2: Create Branch
```bash
git checkout -b feature/your-feature-name
# 或 / or
git checkout -b fix/your-fix-name
```

### 第三步：提交更改 / Step 3: Submit Changes
```bash
git add .
git commit -m "描述您的更改 / Describe your changes"
git push origin feature/your-feature-name
```

### 第四步：创建Pull Request / Step 4: Create Pull Request
1. 在GitHub上创建Pull Request / Create Pull Request on GitHub
2. 选择正确的目标分支（通常是main）/ Select correct target branch (usually main)
3. 填写详细的描述，说明您的更改 / Fill in detailed description explaining your changes

## 📝 贡献规范 / Contribution Standards

### 代码规范 / Code Standards
- 遵循现有的代码风格 / Follow existing code style
- 添加适当的注释 / Add appropriate comments
- 确保代码可以正常运行 / Ensure code runs properly

### 内容规范 / Content Standards
- 使用清晰、准确的语言 / Use clear and accurate language
- 提供适当的引用和来源 / Provide appropriate references and sources
- 遵循项目的指导思想 / Follow project guiding principles
- 保持中英文对照的一致性 / Maintain consistency between Chinese and English versions

### 提交信息规范 / Commit Message Standards
使用清晰的提交信息，例如：/ Use clear commit messages, for example:
- `feat: 添加新的FAQ内容 / add new FAQ content`
- `fix: 修复README中的链接错误 / fix link error in README`
- `docs: 更新贡献指南 / update contributing guide`
- `style: 格式化代码 / format code`

## 🏷️ 标签说明 / Label Descriptions

- **enhancement**: 功能改进 / Feature improvements
- **documentation**: 文档相关 / Documentation related
- **good first issue**: 适合新手的简单问题 / Simple issues suitable for beginners
- **help wanted**: 需要帮助的问题 / Issues needing help
- **translation**: 翻译相关 / Translation related
