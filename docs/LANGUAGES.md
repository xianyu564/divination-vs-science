## 🔄 翻译策略 / Translation Strategy

### 核心原则 / Core Principles
1. **中文优先**: 中文版本是核心维护版本，所有内容更新优先在中文版本进行
2. **中英对照**: 重要文档采用中英文对照格式，确保信息一致性
3. **社区贡献**: 欢迎社区成员贡献其他语言的翻译

### 翻译标准 / Translation Standards
- **准确性**: 保持原意不变，避免歧义
- **一致性**: 术语翻译保持统一
- **可读性**: 符合目标语言的表达习惯
- **文化敏感性**: 尊重不同文化的表达方式

## 🌐 添加新语言支持 / Adding New Language Support

### 贡献流程 / Contribution Process
1. **Fork项目**: 在GitHub上fork本项目
2. **创建分支**: 创建新语言支持分支
3. **翻译内容**: 翻译核心文档内容
4. **提交PR**: 提交Pull Request
5. **审核合并**: 经过审核后合并到主分支

### 新语言要求 / New Language Requirements
- 提供完整的核心文档翻译
- 确保翻译质量和准确性
- 遵循项目的翻译标准
- 提供语言维护者信息
