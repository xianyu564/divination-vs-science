## �� 项目简介

本仓库公开汇集我关于**"玄学是科学吗？"**这一核心问题的系统化思考与应用实践：  
- 讲座用 **Slides**（PDF/PPTX）  
- 对应的 **讲者笔记**（逐页提词/口播稿）  
- 面向读者与产品团队的 **延伸阅读**（学术门牌、方法论）

通过探讨玄学与科学的关系，我们逐步深入到**东方术数(命理、占卜、风水)**的哲学框架，并探讨其在现代决策支持中的应用。

## 🎯 项目定位

### 开源共享部分
- **哲学框架**：关于玄学与科学关系的思考框架
- **方法论**：术数在现代决策中的应用方法
- **学术讨论**：相关学术研究和讨论

### 商业应用部分
- **咨询服务**：基于哲学框架的收费咨询服务
- **APP开发**：基于术数的商业应用（商业机密）
- **创业项目**：按照哲学框架指导的创业实践

## 🧭 指导思想

1. **从问题出发**：以"玄学是科学吗？"为起点，探讨传统智慧与现代科学的关系
2. **哲学框架构建**：建立术数在现代决策中的哲学框架，而非简单的技术应用
3. **启发式思维**：将术数视为启发式工具，用于组织信息和生成行动备选
4. **可测与不可测**：在可量化维度采用实证方法，在不可量化维度采用启发式建议
5. **伦理边界**：不替代专业服务，不做结果承诺，尊重隐私和学术规范
