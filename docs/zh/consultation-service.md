# 咨询服务 / Consultation Service

## 🎯 服务概述

基于"玄学是科学吗？"的哲学框架，我们提供专业的咨询服务，帮助个人和组织在不确定情境下做出更好的决策。

## 🔒 服务性质

### 收费盈利
- **咨询服务是收费且盈利的**
- 基于哲学框架的专业指导
- 结合传统智慧与现代方法

### 服务频次
- **当前以写代码为主，咨询频次偏低**
- 优先服务长期合作伙伴
- 接受预约制咨询

## 📋 服务内容

### 个人咨询
- **决策支持**: 在重要人生决策中提供启发式指导
- **时间规划**: 基于传统节律的时间管理建议
- **环境优化**: 生活和工作环境的优化建议

### 企业咨询
- **战略规划**: 企业发展战略的决策支持
- **团队建设**: 团队协作和沟通优化
- **产品设计**: 基于哲学框架的产品设计指导

### 学术指导
- **研究方法**: 跨学科研究的方法论指导
- **理论构建**: 哲学框架的理论应用
- **学术写作**: 学术论文和报告的写作指导

## 💰 收费标准

### 基础咨询
- **时长**: 1-2小时
- **价格**: 根据咨询内容和服务级别定价
- **形式**: 线上/线下均可

### 深度咨询
- **时长**: 半天/全天
- **价格**: 定制化定价
- **形式**: 现场咨询，包含实地考察

### 长期合作
- **形式**: 月度/季度顾问服务
